1) Project Description

This project is a simple Student Management System developed in C++.  
It allows a user to:
- Add new student records
- Display all student records
- Search a student by ID
- Update an existing student record
- Delete a student record
- Count total students
- Exit the system

All data is stored in a text file (students.txt).


2) How to Run

Step 1: Open the project folder.  
Step 2: Compile the program:
        g++ projectfinal.cpp -o projectfinal.exe  
Step 3: Run the program:
        projectfinal.exe  


3) Files Included

- projectfinal.cpp   → Source code of the project  
- students.txt       → Data file (auto created after adding students)  
- ReadMe.txt         → Documentation file  


4) Notes
